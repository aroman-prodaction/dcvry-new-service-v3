
  # dcvry-new-service-v3

  Prototype v2 for testing service add-to-cart UX during hotel booking.

  Based on `dcvry-new-service-v1`; hourly bath and SPA booking logic follows the interaction model from `dcvry-modification-of-services-v4-git-ready`.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
